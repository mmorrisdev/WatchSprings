# WatchSprings 1.0

The first version of WatchSprings was released for Apple Watch and Wear OS watches in 2019. 

The Fortnite API provider used at that time is no longer around and this app is no longer functioning. However, both projects here compile and run on current setups. 

This code illustrates

- UIKit / Interface Builder on Apple Watch 
- ViewGroup / XML on WearOS

- The use of shared file, class, and function prototype naming conventions across platforms
- A common object hierarchy outside of platform specific areas
